# SIPS · 微醺手册

一个以家庭酒柜为起点的鸡尾酒探索网站。首版采用暖白与植物绿的杂志风格，所有酒瓶与酒杯均为本地 SVG，不依赖图片 API。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm ci --cache /tmp/sips-npm-cache
npm run dev
```

```bash
npm run build  # TypeScript 检查及生产构建
npm test       # 酒柜匹配和补货推荐测试
npm run preview
```

## 已包含

- 首页鼠标跟随倒酒、液面上升、点击控制和重新倒酒。
- 六款经典配方，按基酒、风味、名称和材料筛选。
- 酒柜材料管理、完整配方匹配、缺失材料数量与补货建议。
- 配方详情、1–8 杯用量换算、分步教学。
- 本地保存酒柜与收藏，移动端布局、键盘焦点和减少动态效果支持。

## 继续修改

- `src/main.tsx`：页面、交互、SVG 插画与配方弹窗。
- `src/style.css`：颜色、排版、响应式样式。
- `src/data.ts`：配方数据、材料匹配和补货推荐。
- `src/data.test.ts`：核心匹配逻辑测试。

技术栈：React 19、TypeScript、Vite、Lucide、原生 CSS、Vitest。首版无后端、账号或付费服务；Google Fonts 为可选增强，加载失败时使用本机字体。酒柜初始为空，按需勾选。冰块和水为默认基础用品，不参与匹配；配方中列出的其他材料均参与匹配。份数换算按线性比例显示，多杯调制建议分批摇和。配方为常见做法，具体风味可按个人口味调整。

后续可扩展更多配方、材料替代、计时器、真实照片、自定义配方和云端同步。
